# Excel-Sales-Analysis-Apna-Store
End-to-end Excel sales analysis project where messy raw data was cleaned, transformed, and analyzed to build an interactive dashboard. Used Excel functions like TRIM, XLOOKUP, IF, Pivot Tables, Charts, and Slicers to generate region-wise and product-wise business insights.
